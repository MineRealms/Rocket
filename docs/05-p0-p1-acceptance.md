# P0 / P1 实现与验收

更新：2026-11-25。原始规划见 03；下方旧验收表对应 `6862b1e` / `5a457cd` 时代的运行代码，不自动证明后续 Oculus 和真实地形 LOD 版本通过。当前新增实现见 09，本轮运行证据另列。

## 当前路线

- Forge 1.20.1 / 47.4.29，Java 17，Immersive Portals Forge 3.0.7，Cloth Config 11.1.136。
- IP 负责双世界可见性、维度包路由和自然穿越；ROCKET 负责资格、预热预算、Ready、清理及高度视觉。
- 主世界边界默认 Y1600，对应太空 Y64。x/z、速度方向和朝向不旋转，连续高度 `H = spaceY + 1536`。
- `debugElytraSpaceFlight` 控制当前鞘翅升空入口，未来由火箭实体资格替代。返回和异常脱困不能依赖鞘翅。
- 当前取消同步轨道和方块地球切换，Y1400 至 Space 任意高度保持近地轨道曲面、黑空星点和薄大气边缘。
- Oculus/RocketFlow 路径接入本存档实际 FULL 区块的宽域地表缓存；局部地图仍保留近处细节。无光影回退目前只有局部地图。

## P0：跨界与恢复

服务端每次会话最多额外预热目标半径 2 区块，即 25 个区块；最多 8 个会话。准备窗口 200 tick，确认窗口 100 tick。

客户端 Ready 要求目标 ClientLevel、LevelRenderer、25 个完整区块，以及抵达高度附近的非空 section 已编译。非空抵达区域还要求最近目标渲染 pass；已知全空气区域不依赖玩家朝向或目标绘制 pass。这只覆盖有界抵达区域，不声称全部远景或全部 GPU 资源就绪。

服务器检查 UUID 会话、配置修订、单调回复序号、来源/目标和区块包络。客户端授权无法选择任意维度或坐标。未 Ready 时保存运动并在边界前等待；超时、取消、退出及配置关闭均释放同一个 IP ChunkLoader 引用并恢复重力。

确认丢失时以服务端实际目标维度为准完成会话，后续无会话快照清理客户端旧准备状态，不重复传送实体。

### 太空返回

- 普通下降也可穿过太空 Y64 返回主世界，角色不必滑翔或装备鞘翅。
- 低于太空 Y40 属于异常恢复：清理会话并返回主世界出生点地表，清零速度和跌落距离。
- 异常恢复在 debug 开关关闭时也运行；太空虚空伤害被拦截。
- 新太空区块的生成地板改为空气。旧存档屏障不批量删除，玩家会在到达旧地板之前离开太空。
- 正常 Y64 返回保留高空坐标映射。无滑翔状态返回时提供一次落地伤害保护，最长保留 1200 tick；正距离落地事件、离开主世界、死亡或退出后清理，主世界仍有普通重力。缓降或长时间悬浮超过期限不保证免伤。

## P1：近地轨道与真实地表

`ClientFlightState` 使用服务端同步的映射配置和本地运动插值计算连续高度；服务端每 5 tick 发送权威高度、阶段与会话诊断。

近轨道读取客户端已经加载的主世界列，缓存 256×256 地形颜色/高度图，每格 4 方块，每 tick 最多处理 1024 个样本。它是有限区域的地图代理，不是完整地形 LOD，也不保证每个远景像素与原版方块几何对齐。这份局部地图不额外生成区块；新增宽域 atlas 会按预算生成真实区块。

历史方块地球贴图的来源和再生成方式见 [纹理说明](texture-credits.md)，当前不自动渲染它。宽域 atlas 来自真实 FULL 区块的地表聚合，详情与精度边界见 09。

天空、星空、云和雾随 H 变化。全视野 `orbit_sky` shader 取代原版天空；IP 门户使用 `fuseView`，远端 pass 跳过重复天空背景，避免视距大小的矩形天空窗口。复用 IP 渲染 pass，没有新建递归门户引擎或额外离屏 FBO。动态地形纹理在资源重载后重建，在退出世界时释放。

原生 GLSL 核心着色器使用局部地图；Oculus 扩展在 pack 的 tone mapping 前合成天空像素，积分 Rayleigh/Mie 单次散射并读取真实地表缓存。H1240–1400 渐进转为固定轨道光照，1400 以上 `/time` 不改变地球亮度。它是外观近似，不等于完整多次散射、天气或真实轨道模型。资源重载保留地表 CPU 快照并重新创建 GL 纹理。

宽域 atlas 的粗图先建立覆盖，再逐步细化；它不是逐方块几何。真实生成与缓存需要时间。当前不把完整冷 atlas 细化、多人和 Neo Voxy 兼容列为已验收。

以上光照对比验证 Oculus 路径的一个轨道高度与向下视角。原生回退同样改为固定轨道太阳，但本轮尚未单独实测其昼夜对比。地面日夜仍沿用原光影。轨道地表仍较模糊，局部高精度地图存在明显边界；这些截图不能证明地形表现已完成。

自然往返的首轮截图夹具只在服务端悬停，客户端继续滑翔并发生额外穿越，报告未通过。修正为记录真实抵达事件之后，客户端与服务端均悬停，并在每段开头校验来源维度；随后四段通过。悬停不参与跨界前的推进。

冷区域的五分钟门禁未通过：只完成 339/16384 个实际样本，见 `terrain-atlas-cold-progress.json`；未发生采样失败，但不能据此宣称生成速度满足该门禁。之后的缓存重放单独选择之前采过的区域，不能替代冷生成结果。完整细化和实地几何比对仍待完成。
