# 审查逐项核实

日期：2026-11-25。以下区分提交前代码的事实、推测和本轮处理；游戏结果另记在 05。

| 项目 | 核实结论与处理 |
| --- | --- |
| ResourceLocation 弃用 | 成立；此 Forge 版本提供新工厂，已改为 `fromNamespaceAndPath` / 安全 `tryParse`。未来其他 Minecraft 版本能否编译仍需独立迁移验证。 |
| 非法配置 ID / null 物品 | 成立；验证器不再抛 ID 解析异常，物品集合过滤 null，并提供初始空集合。 |
| shader 的 0.0001 | 成立；它是画面故障隔离时的临时输出，已移除。不能把这版临时画面当最终效果。 |
| 低空雾近平面为 0 | 成立；低空保留原版雾，高空才插值且保留正的近平面。 |
| Long.MAX_VALUE 回复 | 可污染一个合法会话的后续回复；原有 200 tick 超时会终止会话，并非永久卡死整个状态机。已增加每会话顺序、上界及每 tick 应用预算。 |
| 相同 revision 客户端早退 | 原代码拒绝的是更旧 revision，等值 CONFIG 仍会处理。服务器同 JVM 重启和同值配置重载后的重发确有缺口，已加 dirty / loadRevision，并在新 revision 重置准备序号。 |
| 3×3 / 5×5 | 原说法不成立；客户端与服务端均检查完整 5×5 区块。两侧的 `< radius` 都限制玩家相对中心的移动范围，留一圈预热余量。 |
| smoothRange 非法输入 | 原先会抛异常；渲染工具函数已改为安全返回 0，非法相机高度不送入绘制。 |
| null shader | 保存 null 本身不会立即抛异常，之后的绘制存在风险；恢复时已提供默认 shader，补全混合因子恢复。 |
| 每 20 tick 兼容层抛异常 | 维度缺失分支原先仅日志，并不 throw；创建实体返回 null 的分支会 throw。现改为失败返回、100 tick 重试间隔，并在两端安装成功后才发布已安装状态。 |
| 太空相位忽略滑翔 | 设计行为；轨道相位表示位置，不是资格。太空中的普通自由落体必须能够进入返回流程。 |
| 网络处理器与速率 | 未复现 setup 前有 PLAY 包造成丢包，但直接安装处理器并使用 volatile 可消除额外排队/可见性缺口。已增加每会话合法回复预算；这不是完整网络抗洪系统。 |
| 动态纹理重载 | 静态 Java 引用确实不能作为 GL 资源有效的证明；现于 shader 重载标记失效，在下一次渲染重建并重新采样。 |
| 多维 pass 雾 / 死代码 | 已重写为当前 IP 切换后的 ClientLevel 与相机高度，融合目标 pass 跳过重复背景；删除未使用的高度计算。 |
| mandatory 依赖 | 当前为真实强依赖；直接使用 IP 类，IP 又要求 Cloth。改 false 会把清晰的缺依赖提示变成类加载失败。 |
| 第三方日志 | Mixin minVersion / 目标类警告需按具体日志归属；不能因为它们来自依赖，就把新的 shader 编译或本项目异常也归为噪音。 |

复现探针 `tools/probes/review_regressions.java` 检查非法 ID、null 集合、非法视觉输入、有效会话中的超大序号及随后正常回复、同值配置重载。其余仍用实际跨界、资源重载和画面采集验证。
