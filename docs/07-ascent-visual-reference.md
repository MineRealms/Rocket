# 地面到近地轨道的视觉依据与高度映射

更新：2026-11-25。本文是渲染设计参考，不是已经通过游戏实测的效果说明。

## 一、真实观察与本项目取舍

| 阶段 | 有依据的视觉现象 | 本项目应采用的画面 |
| --- | --- | --- |
| 地面白天 | 分子对短波散射较强，天空呈蓝色；视线方向、太阳方向和空气路径共同决定颜色。[NASA：蓝天](https://spaceplace.nasa.gov/blue-sky/en/) | 保留原版地面识别度；远景有空气透视，天空不是一张随高度整体变黑的色纸。 |
| 穿越天气层 | 对流层高度约 8–14.5 km，几乎全部天气发生于此；平流层在其上，通常较少云与天气。[NASA：大气分层](https://www.nasa.gov/image-article/earths-atmospheric-layers-3/)、[NASA：多层大气](https://science.nasa.gov/earth/earth-atmosphere/earths-atmosphere-a-multi-layered-cake/) | 云层由头顶转到脚下，穿云可短暂失去能见度；云不能永远追着相机高度走。远地表由细节转为色块。 |
| 高空到大气边缘 | 空气密度逐渐降低，没有大气到真空的实体硬边；轨道照片中地球边缘呈薄蓝色带。[NASA：大气顶部及 ISS 照片](https://science.nasa.gov/earth/earth-observatory/the-top-of-the-atmosphere-7373/) | 天顶先明显变暗，斜向长路径仍保留蓝白散射；逐渐收缩为贴近地平线的薄层。不能在某一高度把整个天穹同时切成黑色。 |
| 近地轨道 / ISS 视觉 | ISS 平均高度约 400 km；近地轨道仍贴近地球，近地平线显示很薄的蓝色大气边缘，黑色空间位于其上方。[ESA：ISS](https://explorationscience.esa.int/platforms/international-space-station/)、[NASA：从轨道看到的大气](https://www.grc.nasa.gov/www/k-12/airplane/atmosphere.html) | 用户指定：进入 `rocketmod:space` 后仍保持 ISS 风格近地视野：宽阔地表、受控的轻微曲率、贴近地平线的薄蓝大气、黑色星空。不要切换到完整地球圆盘或方块地球。 |

FAI 使用 100 km 卡门线作为空间边界的约定；它不是突然变黑、开始看见星星或大气完全消失的高度。[FAI：卡门线声明](https://www.fai.org/news/statement-about-karman-line)

**星空、曝光与光照：** 黑背景不等于白天一定能看到密集星空。NASA 说明，以明亮地球、月面或日照物体设置的短曝光通常拍不到暗星。游戏可以保留少量引导性亮星，但应标明这是艺术选择；密集星空宜随背景变暗、视线离开明亮地球和曝光适应逐渐出现。不要将星星透明度只绑定高度。[NASA：星星在哪里](https://science.nasa.gov/blogs/earth-matters/2011/09/28/where-are-the-stars/)

大气散射消退不意味着太阳照明消退：白昼地表、云和飞行器应继续明亮。太阳方向贯穿全程；从 LEO 到 GEO 不需要把太阳画得显著缩小。昼夜交界由光照方向决定，不能用高度控制整颗地球统一变暗。薄蓝边应主要附着在受照侧和掠射视线附近，不能成为绕夜侧同样耀眼的霓虹描边。

## 二、建议游戏高度序列

默认物理切换高度 **T = 1600**，海平面基准 **B = 64**。地面段统一参数 `u = clamp((H-B)/(T-B), 0, 1)`；这是游戏节奏，不宣称一个方块对应真实一公里。`T=1600` 只定义进入 Space 的物理边界。切换前逐渐建立近地轨道的黑空、星点和大气边缘；跨界不重启过渡。进入 Space 后保持同一近地轨道视觉，不定义同步轨道完成高度或第二个 `v` 过渡。

| 游戏高度（默认） | 相对阶段 | 可直接实施的目标 |
| --- | --- | --- |
| 64–294 | u = 0–0.15 | 原版蓝天为主；弱空气透视，地形细节与近云保持稳定。 |
| 294–602 | u = 0.15–0.35 | 穿越云层，云逐渐位于视线下方；地表远景色块与地平线雾先出现。 |
| 602–986 | u = 0.35–0.60 | 天顶由蓝到深蓝，地平线仍较亮；渐进减少高角度散射。不能全屏灰幕。 |
| 986–1370 | u = 0.60–0.85 | 天顶接近黑，蓝色收束到较窄的地平线带；下方仍是广大的平直地面与云海。 |
| 1370–1600 | u = 0.85–1 | 完成大部分天空变化；在门户另一侧复用相同高度、太阳、雾和代理地形状态。物理切换点不承担一次新的美术转场。 |
| 1600 及以上 | Space / 近地轨道 | 黑色空间与稀疏星点连续；地表仍是宽阔的近地轨道地平线，轻微弧度和薄蓝大气边缘保持稳定。高度继续增加不触发地球缩小或方块地球渲染。 |

游戏高度不对应真实公里数。近地地平线的可见弧度与 ISS 参考画面是风格化映射，不是 Minecraft 世界真的变为球体，也不是物理轨道模拟。

## 三、可用数学与 shader 约束

### 真实角尺寸只用于判断量级

球形地球半径取 `R = 6371 km`，从表面高度 h 观察，完整轮廓角直径为 `D = 2 asin(R/(R+h))`，地平线相对当地水平面的俯角为 `d = acos(R/(R+h))`。这是几何推导，不是照片镜头参数。

| h | D（约） | d（约） |
| --- | --- | --- |
| 100 km | 159.8° | 10.1° |
| 400 km | 140.4° | 19.8° |
| 2,000 km | 99.1° | 40.5° |

所以普通视场的近轨画面通常容不下整个地球。本项目当前不渲染完整地球轮廓；只用受控的地平线曲率来表达近地轨道视角，不使用球体或方块远景。

### 大气不能只做高度渐变

用每像素世界视线 `ray` 与太阳方向 `sun`，至少分开计算天顶散射、掠射地平线散射、太阳附近气溶胶亮区以及地表空气透视。常见近似为 `rho(h) = exp(-h/Hs)`，沿视线积分光学厚度 `tau = integral(rho ds)`，透射率 `Tr = exp(-beta * tau)`；颜色由透射后的背景加沿程散射组成。`Hs` 是模型尺度高度，不能拿游戏维度切换阈值直接替代。

真实渲染资料：[NVIDIA GPU Gems 2，第 16 章，Sean O'Neil：Accurate Atmospheric Scattering](https://developer.nvidia.com/gpugems/gpugems2/part-ii-shading-lighting-and-shadows/chapter-16-accurate-atmospheric-scattering)；[Eric Bruneton：Precomputed Atmospheric Scattering，新实现及验证](https://ebruneton.github.io/precomputed_atmospheric_scattering/)。前者给出从地面到太空的密度、光学厚度与散射实现，后者给出预计算、太阳光谱及臭氧等可扩展模型。项目若采用简化模型，应称“参考大气散射的艺术近似”。

所有高度权重使用平滑函数，例如 `s(x)=x*x*(3-2*x)`，且天空、雾、地形代理与门户两侧必须共享连续的绝对高度参数。单独 smoothstep 每层透明度仍可能出现重影、亮度翻倍和色彩跳变；组合时应保持遮挡与透射关系，在正确色彩空间中混合。

**验收重点：** 固定太阳和相机方向，对天顶、水平、俯视分别连续上升与下降拍摄；对准 1600 上下检查天空、云层、地平线和地表尺度，跨界前后不得突变。Space 中的天顶应为黑色并有稀疏星点，水平视线应保留薄而克制的蓝色大气边缘，地表维持近地尺度。任何 Space 高度都不得启用完整圆球或方块地球。日间同时检查地表受光与星空抑制，夜间检查星点与气辉。
